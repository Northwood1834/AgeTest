## Generated assets

The three `assets/date-*.webp` files and `assets/partner-mood.webp` were generated on 2026-07-25 for this repository using local ComfyUI with Krea2 HD through the Photobook/Terra image workflow. Prompts required fictional, clearly adult, single-person, SFW characters in a book café, film set, museum lounge, and rainy home-kitchen conversation scene. Each image uses a different person and setting; the partner image is mildly displeased but non-threatening. They were resized to 768×960 WebP and visually checked before integration. Future image generation for this project should use the same Photobook/Terra review path unless the author changes that instruction.
